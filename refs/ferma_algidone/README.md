# Ferma Algidone! — art package (M0 → M1…M6)

Generated by the owner with Gemini 3.1 from prompts written on the planning side (Claude web, "Mangiapietra"
project), then cleaned and cut there: chroma background removed, snapped to the art's own pixel grid,
palette-reduced, cut into frames, frames of one animation padded to a shared cell.
**Nothing here is embedded in `index.html` yet.** Original 4K Gemini sheets are kept by the owner (too big for the
repo, ~180 MB); `_pipeline/` has the scripts used, so a regenerated sheet can be cut the same way.

- `frames/*.png` — pre-cut transparent frames, one file per key (prefix `fa_` = Ferma Algidone).
- `ferma_algidone_frames.json` — per key: `file, w, h, anchor, source, note`, plus `animations` (frame order).
- `preview.png` — contact sheet of everything.

## Rules
- **1 art pixel = 1 image pixel.** Draw with `imageSmoothingEnabled=false`; integer scale preferred.
  In-game draw size is decided in code relative to D1's tile size (sizes below are the art's native size).
- **Anchors**: `bottom-center` = feet / base on the bottom-centre of the cell. All 14 `fa_alg_*` frames share
  one 124×158 cell, so switching animation never jumps. `center` = free item. `fill` = full backdrop.
- **Uomo roccia (the climber) has no new art**: he climbs with the existing `fu0`–`fu3` frames animated in code
  (alternating tilt/squash); jump, death, kick-out (headbutt) and celebrate are also code-only on existing frames.
  So no new GEKA skin frames are needed either.
- Girders, ladders, broken ladders, conveyor belts, elevators/rivets stay **code-drawn**, recoloured per floor.
- Sausage roll-rotation, porchetta wobble, flame/grill glow timing are done in code.
