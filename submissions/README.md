# Submissions
Your space. Each developer puts changes in `submissions/<your-name>/<YYYY-MM-DD>/` with a `manifest.json`
(see `_template/manifest.json`, and `_example/` for a filled one) plus any audio/sprite files it references,
then opens a pull request. Full guide: [DEVELOPERS.md](../DEVELOPERS.md).

Submissions are NOT published. They only become part of the game once verified and hardcoded into a new build.
