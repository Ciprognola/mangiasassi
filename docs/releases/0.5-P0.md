### 1b. Girone → map, run length, girone-5 split
- `pickMap(prev)` (L3466): extra maps locked → uniform over the 5 standard maps, never the same as the previous one. Unlocked (`mapsUnlocked()`, L3465 = achievement `g4` «Sale la carriera», level 10 with any character, or SIM) → **75% one of the 10 extra maps, 25% one of the 5 standard**, no immediate repeat (the 0.2_45 weighting).
- Called at run start (`startGame`, L3620) and on each girone clear (`update`, L3861: `G.stage++`, lives refilled to 3 unless `G.hard`, new map, `resetActors`, then `bjAfterClear()`).
- A run has **no girone cap**: it ends only when lives reach 0 (`update` dying branch, L3860 → `finishRun`) or on «Abbandona partita» / «Salva ed esci» (`pauseMenu`, L3757).
- Split: reaching girone 5 in a non-dev run sets the permanent `S.p.g5` (L3861). `renderMenu` (L2113) then splits the «Nuovo gioco» tile into «Nuovo gioco» + «Hardcore» (`data-tile="hard"`); `tileAction` (L2130) starts `startGame(false,{hard:true})`.
- Hardcore differs **only** in lives: 4 at start, no refill between gironi (L3620, L3861); «Ancora!» on the over screen keeps the mode (L4205). Rewards, speed, maps are identical.
- Other girone-based events in a run: El Gamblador guaranteed on reaching girone 5, Ferma Algidone! possible from 5 (§5b); `miniInterlude` card every girone multiple of 5 when no mini-game fires (L4850); secret ability from girone 7 (`abilOn`, L3628; `S.p.sec` set on reaching 7, L3861). Player speed `5+min(1,stage*.08)` (L3869) and ghost speed (§2b) rise with the girone.

### 1c. «Start at girone 3» after a professor win
`pbEnding` (L7057): on a win (not `PR.test`) asks yes/no; yes → `startGame(false,{stage:3,score:M.reward})` (L7077) = a normal new run (3 lives, `pickMap(-1)`, current menu difficulty/character) starting with `G.stage=3` and `G.score=pbReward(L)`; no → `S.p.sordi+=M.reward` directly (L7078). `pbReward(L)=round(70*(1+L/10)^1.6)` (L6292), L = the ghost's level from `pbFoeLevel` (`pbMatch`, L6320). The seeded score is converted by `finishRun` like any other score.

## 2. Ghosts

### 2a. Count
Always **4**, for every map, girone and difficulty: `resetActors` (L3599) creates one enemy per `MET.ghosts` entry (4 in `DEFMETA` and in every `NEWMAPS` meta). Tints `TINTS` (4, L3559). Difficulty changes behaviour, not count.

### 2b. AI and data
- Per ghost (L3602): `wait=(i*2.2+1.2)*dfc().wait` release delay (then leaves the house moving up, L3909), `chase=dfc().chase[i]`, `mode` `n`=normal / `s`=scared / `g`=eaten.
- `DIFF` (L425–427), `dfc()` (L428, defaults to `hard` when no run): Facile `spd .82, wait 1.5, chase [.3,.2,.12,.22]`; Media `.91, 1.25, [.52,.38,.24,.41]`; Difficile `1, 1, [.75,.55,.35,.6]`; `mult` .8/.9/1.05 is the reward multiplier (§4).
- Speed (L3906): `min(5.7, 4.3+stage*.18) * dfc().spd` tiles/s (cap reached at girone 8), ×.72 when scared, × terrain factor `terF(e)`.
- `chooseE` (L3809), called at each tile centre by `step` (L3793): candidate directions = not a wall and **never a U-turn**. Normal: with probability `e.chase` picks the neighbour closest (Euclidean) to the player's current position, else random. Scared: 55% the neighbour farthest from the player, else random. **No scatter mode, no pathfinding, no per-ghost targeting offsets** (unlike Pac-Man) — the only difference between the 4 ghosts is `chase`/`wait`/tint.
- Power-up: `spawnGlow` (L3828) after 12 s, or from 8 s (10 s after a previous power-up) with chance `dt/2.5` per frame. `activatePower` (L3838): `G.power=15`, every non-eaten ghost → `s` and `reverseE` (L3823) if already released. At 0 the scared ones return to `n` (L3897).
- Eaten ghost `eatPlane` (L3843): score `min(1600,100*2^chain)` (200/400/800/1600), respawns on a random cell ≥6 tiles away as `g` for 5 s (drawn transparent with a countdown, harmless), then back to `n`/`s`.
- `PLANES` (L321, 25 names), `GYM` (L412, 25), `ROCKS` (L323), `SNACKS` (L413). The selected enemy `G.plane` (from `cs().selP`) is used for **looks** (`artOf(G.plane)`, L4113) and for achievement filters (`ach("eat"/"foe",{pl})`: r4, r5, a3, a4, a5, L3259–3267). It changes no speed/AI/score. Same for the selected rock/snack `G.rock` (pellet art + achievement filters).

### 2c. Enemy art and skins
Enemy art is **procedural only**: `artOf(i)` (L322) returns 1–5 for the first five enemies, 0 otherwise. Roccia: `drawPlane` → `planeCv` (L1593/L1610) with pixel grids `ART[1..5]` (L1560, `APAL` palettes) or the generic `PLANE_ART` (L1546). Algidone: `drawGymArt` → `GYMA[1..5]` (L1630, animated, `GPAL`) or the generic `drawGym`/`gymCv` (L1772/L1779). `burgerCv`/`cupCv` (L1758/L1764) are the snack/power-up, not enemies.
**Not covered by skins**: `SKIN_DEF` (L2833) has only `roccia` and `algidone` character frames; enemies are not in the sheet, `SKINS`, `SKIN_COVERAGE.md` or §6 rule 11 (which covers "a frame, pose or animation of a character").

### 2d. Player–ghost collision (B1)
- `update` (L3910–3915): after each ghost moves, `Math.hypot(ex-px,ey-py) < .62` (tile units, continuous positions from `pos()`, L3801) → scared: `eatPlane`; else death unless `G.invuln` or **any ability active** (`G.st.on` — Acciaio *and* Cinghiale both make you immune).
- `G.invuln` is decremented (L3863) but **never set above 0** anywhere (reset to 0 in `resetActors`/resume): there is no respawn invulnerability in the maze.
- Other radii: pellet pick `< .45` on the rounded tile (L3900), power-up `< .5` (L3899), lava contact `< .6`, water `< .7` (L3886–3895).
- Drawn sizes (`draw`, L4058): enemies `c*1.05` square (L4117–4124), Uomo roccia face `c*1.5` wide (`drawHero`, L1814), Algidone `c*1.7` tall (`drawAlg`, L1783). Collision is a single centre-distance test, independent of sprite size.

## 3. Systems to reuse

### 3a. Terrain slow
- Stored in the map rows: `~` water, `^` lava (L3477 comment). `setDims` (L3558) sets `TERR` = the map rows; `freshGrid` rewrites `TERR` keeping streams off the house/start/tunnel ends. `terAt(x,y)` (L3481) → `"w"`/`"l"`/`""`.
- Streams generated by `addStreams(rows,spec,seed,meta)` (L3488, seeded LCG, sinuous paths along corridors, avoids tunnel rows, house ±1 and start ±1); `hardenMap` (L3524) + `mapReach` (L3509, BFS on burn time) turn unreachable lava back into floor.
- `terF(e)` (L3792) = `LAVA_SLOW .6` / `WATER_SLOW .75` / 1 at the actor's rounded tile. Applied to the player (`P.speed`, L3869) **and to ghosts** (`e.speed`, L3910).
- Lava damage/burn (`G.burn`, 3 s = death, `LAVA_KILL`) and water cooling are player-only (L3886–3895). Ghosts are slowed but never burn.
- **The 5 standard maps contain no `~`/`^` at all** (table above): terrain exists only in the 10 extra maps and the 2 dev maps.

### 3b. `smash()` / Cinghiale
- `chooseP` (L3802): while the boar is on and stress < 100, a wall in the wanted/current direction that passes `smashable(x,y)` is removed.
- `smashable` (L3658): `x∈[1,W-2]`, `y∈[1,H-2]` and cell is `#` — this is the only border protection (outer ring untouchable). It does **not** exclude the ghost house or tunnel rows.
- `smash` (L3690): `G.grid[y][x]=" "` (walkable, no pellet), stress +16 (`BOAR_STRESS`), crack/debris/smoke `G.fx`, shake, `sfxSmash`. At 100 stress `boarOff(true)` → stunned 3 s (`STUN_T`).
- No pathfinding refresh is needed or exists: all movement checks `wall()` (L3562) against the live `G.grid` at every tile. The changed grid is saved with `quicksave` (L3768, whole `G`).

### 3c. Particles, projectiles, line of sight
- `G.parts` (L3620): simple grey squares `{x,y,vx,vy,l}` with gravity, drawn L4159 (eat, teleport, eaten ghost).
- `G.fx` (L3609): `smoke` / `deb` / `crack` effects, updated L3882, drawn L4150–4157 (boar smoke, smash, lava embers, water steam).
- **No projectile system in the maze** and **no line-of-sight helper**. Reusable grid helpers: `mapReach` (BFS from the start), random-cell pickers in `spawnGlow` (L3828), `eatPlane` (L3843) and `steelTeleport` (L3637), `wall()`, `pos()`, `step()`.
- Ferma Algidone! has its own items/particles (`FA.items`, `FA.fx.parts`), separate from the maze.

## 4. Rewards — maze run pipeline (as it runs today)

In-run score (`G.score`):
1. Pellet +10 (L3901). Pellets are capped at 130 on big maps (§1a), so a big map gives no more pellet points than a standard one; there is no other map-size weighting of rewards (the 0.2_45 "bigger-map weighting" is only the `pickMap` 75% bias).
2. Girone clear +200 (L3904); also `S.p.ch[char].gir++` (career/Percorso counter, non-dev).
3. Ghost eaten during a power-up: 200, 400, 800, 1600 (chain reset at each power-up and at `resetActors`) (L3844).
4. Encounters change `G.score` directly: El Gamblador bets/wins on the run score (`bjScore`/`bjSetScore`, L4375–4376); Ferma Algidone! adds its final score + stock bonus when the encounter is won (`faEncPay`, L5034); professor win seeds a new run's score (§1c).

End of run — `finishRun(o)` (L4186), same for quit («Abbandona», `quiet`) and game over:
- `lim = limiter(cc.lvl)` (L435): 80% at level 1 → 65% at 50 → 50% at 100 (hidden withholding).
- **Sordi** `gain = floor(score * (1-lim) * DIFF.mult * .7)` — `.7` is the 0.2_59 −30%. `DIFF.mult` = .8 / .9 / 1.05.
- **XP** `xp = floor((floor(score*.6) + (stage-1)*20) * DIFF.mult)` → level-ups via `expNeed` (L439).
- `G.dev` runs: 0 sordi, 0 XP, no best score. Then achievements `sordi/run/score/level`, `S.quick=null`, `persist()`, `cloudFlush()`, over screen (or menu + toast when quiet).

Outside the run formula:
- Achievements `unlockAch` (L3311): each pays `r[0]` sordi + `r[1]` XP × `AMULT` (.75 / 1 / 1.5 by difficulty, L3242), XP to the achievement's character.
- Professor win, «no» to girone 3: `pbReward` straight to sordi (L7078).
- El Gamblador and Ferma pay nothing directly; they only move `G.score`, which `finishRun` converts.
- Roadmap tiles give skins only (`roadGrantReward`, L3435).

## 5. Start flow and encounters

### 5a. «Nuovo gioco» → `startGame`
Tile `new` → `tileAction` (L2130): if a quicksave exists, `confirmBox` to overwrite, then `startGame(false,null)` (L3617): `pickMap(-1)`, `G={stage:1,score:0,lives:3,hard:false,grid,diff:S.opts.diff,char:S.p.char,mapi,plane:cs().selP,rock:cs().selR}`, `resetActors`, `ach("dbg_new")`, `screen="game"`, `buildGameDOM` (L3717). Per character only `G.char`/`plane`/`rock` differ (art, sounds, ability type); speeds and rules are identical. «Gioco corrente» = `startGame(true)` from `S.quick`.

### 5b. Encounter triggers — `bjAfterClear` (L4835), called after every girone clear, with `st = G.stage` already incremented
- **El Gamblador**: wanted when `st===5` (i.e. on reaching girone 5) or `st>5` with 15%; it only starts if `bjPrice(G.score, S.p.gam.visits) >= 50` (L4285: needs ≥50 run points). → `startGamblador({run:true})` (L4820), `S.p.gam.visits++`; `bjExit` (L4784) rebuilds the maze.
- **«Non ora»**: `bjPresent` (L4675) hides it when `B.run && !B.visits`, where `visits = S.p.gam.visits` — a **lifetime** counter that is never reset. So it is hidden only on the **first-ever** table, not on the first appearance of each run as CLAUDE.md §2 states.
- **Ferma Algidone!**: from `st>=5`: forced if `S.p.fa.enc===0 && st>=10`, otherwise 15% only when El Gamblador did not start (L4847). Dev/SIM runs: only through `FA_FORCE`. → `faInvite` (L4854; no «Non ora» only when forced) → accept: `S.p.fa.enc++`, floors asked `n=min(enc,3)` → `startFerma({run:true,encounter:n,mult5})`. Refuse or finish → `faResume` / `faBackToMaze` (L4868–4872).
- Priority: forced Ferma > El Gamblador > random Ferma; one mini-game per interval; otherwise `miniInterlude()` on multiples of 5.
- `nextMinigame()` (L3771) has no order logic: it always returns «Mangiaroccia» (`restart:true`) for the interlude card.

### 5c. Ferma Algidone! today

**Entry and modes** — `startFerma(o)` (L4935), options `level, test, debug, extra, goal, finale, run, encounter, mult5, dev`. `FA.test = o.test || !o.run`. Practice (Giochi card «Gioca», L2208) = `{test:true}`: 3 floors, Riprova, no rewards/achievements. Encounter = `{run:true,encounter:n}`: `FA.enc={n,run,mult5,dev}`, no Riprova (`faOver` shows only «Continua»), «Avanti» until floor n then «Continua». Only a real encounter (`faReal()`, L5028: enc + run + not dev/SIM + `G` not dev) sets achievements (`faClear`: m2/m3/m4), `S.p.fa.f1` (roadmap tile 10) and pays (`faEncPay`: whole score added to `G.score` only if all n floors are cleared). Lost encounter → nothing, maze run continues.

**Data** — `FA_LEVELS[0..2]` (L4889): Coccia, Macelleria (belts on girders 2 and 4), Fabbrica (`bolts`, grill, flames, `last:true`). All three share the same girder/ladder layout. Per floor `items` = throw weights, `throwMin/throwMax`, `ladderP`, `stock:90`.

**Difficulty (M9b)** — `FA_DIFF` (L4952): Facile/Media/Difficile `spd .88/1/1.12` (item speed, `faSpawn` L5217), `pause 1.25/1/.85` (throw interval), `drain .85/1/1.15` (stock). `FA.dm` from `G.diff` in an encounter, `S.opts.diff` otherwise. Fixed for the whole session; no per-loop scaling exists.

**Lives / score** — 3 lives at floor 1; `faNextFloor` (L5105) carries lives and score to the next floor (no refill). Death (`faDie`, L4997): −10 s stock (`FA_DEATH_STOCK`), 0.8 s pause, respawn with 2 s invulnerability, all items cleared. Game over when lives = 0 or stock = 0. Score `FA_SCORE` (L4996): jump over sausage 10, porchetta 30, meat 10, flame 20; bolt 50 (`FA_BOLT_SCORE`); floor-end bonus `floor(stock)*10`.

**Level timer (the «scorte» stock)** — set to `FA.lv.stock` (90 s) by `startFerma`/`faLoadFloor` only (not on respawn). Drained **by the clock**: `FA.stock -= dt * FA.dm.drain` every play step (`faStep`, L5139), plus −10 on each death. Frozen during intro, pause, dying, climb/collapse/win. Displayed by `faHud` (L5107): bar `#fastbar` (red under 25%) and the `scorte0..3` pile image; beep every 2 s under 25%. At 0 → `faOver()` immediately, regardless of lives.

**Algidone eating** — pure animation, **not linked to the stock**: in `faAlgStep` (L5230), each time the throw wait ends, if not «angry» (`faAngry`: player on the top two girders or stock < 25%) there is a 22% chance (`FA_EAT_P`) to play `alg_eat0-2` for 1.65 s (`FA_EAT_T`) instead of throwing. Also forced on player death (`faDie`). The `meatHop`/`grill` items are thrown objects, unrelated to his eating.

**Throw rate** — after each throw or eat: `wait = (throwMin + rand*(throwMax-throwMin)) * FA.dm.pause`; per floor 1.6–3.0 s (floor 1), 1.4–2.6 s (floors 2–3); 2.5 s grace after (re)spawn (`faRespawn`, L4989). Throw anim 4×0.14 s, item released at frame 2; max 14 items (`FA_MAX_ITEMS`).

**Floor 3 bolts** — positions are **fixed data**: `FA_LEVELS[2].bolts` (L4921) = 8 bolts, two per girder 1–4 (`{g:1,x:150},{g:1,x:255},{g:2,x:130},{g:2,x:220},{g:3,x:120},{g:3,x:240},{g:4,x:140},{g:4,x:265}`), copied by `faInitBelts` (L5202). `faBoltPick` (L5206): walking over one on the ground (±9 px) removes it; 0.5 s later a hole ±13 px (`FA_GAP`) opens (`faBoltsStep`); the player and items fall through (`faInGap`, L5253); a fall > 115 px kills (`FA_PHYS.fall`). Last bolt → `faFinalWin` (collapse). **No code checks beatability**: the positions are hand-placed away from ladder x's (ladders at 60/190/210/230/300) with no validator; the only structural safety rules are `safeXEnd:90` (no hits near the start), `flameMinX:150`, `stopLeft`.

**What blocks the planned «Ferma as a full run»**
- (i) Looping: `FA_LEVELS` has 3 entries; `faNextFloor` refuses `level+1 >= FA_LEVELS.length`; floor 3 only offers «Rigioca» (= `faLoadFloor(0,3,0)`, resets lives/score) or «Esci»; there is no loop counter, and difficulty `FA.dm` / bolt positions / throw timings never change after start.
- (ii) Girone counter: gironi live only in the maze `G` (`G.stage`, `S.p.ch[c].gir`, `S.p.g5`, `S.p.sec`, achievements `stage`/`clear`, `roadGir()`) — all updated only in the maze `update` clear branch. Ferma has only `FA.level`.
- (iii) Encounters between Ferma floors: `bjAfterClear`, `startGamblador({run:true})`, `bjExit`, `faInvite`, `faResume`, `miniInterlude` and `finishRun` all read/write the maze `G` (score, stage, state `"mini"`, dev flag) and return by rebuilding the maze DOM (`buildGameDOM`). `FA` is a single global: a Ferma encounter started from a Ferma run would overwrite it; `faExit` returns either to the maze (encounter) or to the menu. Rewards are only converted by `finishRun`, which needs a maze `G`. There is no Ferma save/resume (`S.quick` holds only a maze `G`; Ferma only auto-pauses on `visibilitychange`).
- Also: the climber is always Uomo roccia (`faDrawPlayer`, HUD lives drawn with `drawFace`) whatever character is selected.

## 6. Firebase / accounts

### 6a. `firestore.rules` (repo copy)
- `devs/{uid}`: read own doc only; no client writes (roles edited in the console).
- `saves/{docId}`: read/create/update only own doc (`uid` or `uid_dev`); fields exactly `data,rev,ts,ver`, `data` string ≤ 900 000 chars, `ts == request.time`, create `rev==1`, update `rev == old+1`; **delete: never** (clients). Any signed-in user (player or dev) qualifies.
- `bugs/{id}`: create only if `isDev()` (a `devs/{uid}` doc exists), `uid` = caller, `text` 1–1000 chars, fields `uid,text,screen,version,char,ts,ua,meta`; no read/update/delete.
- `edits/{id}`: create only `isDev()`, fields as listed, `kind` text/colour/scale, value ≤ 500, note ≤ 300; no read/update/delete.
- So a **player** may today: sign in, read `devs/{own uid}` (gets "not found"), read/write their own save. Nothing else.

### 6b. `bugs-export.yml`
Secret **`FIREBASE_SA`** (service-account JSON), passed as env to `tools/bugs/export_bugs.py`, which `pip install firebase-admin` and calls `credentials.Certificate(json.loads(sa))` + `firebase_admin.initialize_app` (L135–144). Daily cron `0 6 * * *` + manual run, `contents: write`, checks out `dev`.
The Admin SDK ignores security rules (so `saves` "delete: never" does not bind it) and includes `firebase_admin.auth` (list users with last-sign-in metadata, `delete_user`). Whether **this** service account's IAM role allows Auth user management is not visible in the repo (it depends on which account the owner created in the console); the current script only touches Firestore.

### 6c. Login code
- Shared: `fbLoad` (L516, SDK 12.19.0 via `import()`, 8 s timeout, `file:` refused), `FB_DOM="@mangiasassi.invalid"` (L514), `fbRoleOf` (L529), `fbErr` (L535).
- Dev: `loginModal` (L2371) → `fbLogin` (L545): sign in, role from `devs/{uid}`, no role → sign out + «Account senza ruolo.».
- Player: `plLogin` (L587) — same sign-in; role → dev session, no role → `playerAcct=user`; UI `plAccountHTML` (L619) + `plLoginGo` (L608); `plLogout`, `plVerify` (L595–606).
- Failed attempts: **no local counter or lockout**; the only handling is Firebase's own `too-many-requests` → «Troppi tentativi: riprova più tardi.»; the «Accedi/Entra» button is disabled during the attempt and re-enabled on error (the known Esc-focus bug, §8 backlog).
- Username validation (both forms): `trim().toLowerCase()`, must be non-empty, must not contain `@`. No charset/length rules.
- Sign-up: none exists (accounts are created in the console). The plug-in point would be the player form (`plAccountHTML`/`plLoginGo`); `fb.Au` is the full auth module already loaded by `fbLoad`, and a new account with no `devs` doc falls into the player path of `plLogin`.
- Password change: `fbChangePw` (L553, min 6 chars, re-authentication). No reset (the `.invalid` domain receives no mail).

### 6d. The flags (L1071–1073)

## Surprises / risks found
1. The 5 standard themed maps (Acciaio, Acqua, Fuoco, Ghiaccio, Foresta) have **no water/lava**; terrain only exists on the 10 extra maps (level-10 unlock).
2. El Gamblador's «Non ora» is hidden only on the **first-ever** table (lifetime `S.p.gam.visits`), not per run as CLAUDE.md §2 says.
3. `G.invuln` is never set: no invulnerability after losing a life in the maze (Ferma has 2 s).
4. Cinghiale (not only Acciaio) makes the player immune to ghosts while active.
5. Two extra maps (Caverna 141, Neon 139 pellets) are below the cap threshold, so they give more pellets than 130.
6. `nextMinigame()` always returns «Mangiaroccia»; `rankOf` is dead code.
7. Ferma is tied to the maze `G` at every exit/reward point and uses one global `FA`: the planned full-run mode touches `bjAfterClear`, `bjExit`, `faInvite/faExit`, `finishRun` and quicksave, not just Ferma itself.
8. `smashable` does not protect the ghost house or tunnel rows (only the outer ring).
