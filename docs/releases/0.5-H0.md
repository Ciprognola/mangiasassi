Written for: the owner and the Claude chat planning the handheld plan (roadmap §7). Base: `index.html` at 0.5 (`const VERSION="0.5"`, commit `f9d69d7` plus the 0.5_1 controller test). Line numbers are from the single-file build and drift with every patch; search the names, not the numbers.

## 1. Screens: how the layouts are built

The root is `#root` (`index.html`, CSS line ~32): a column, `max-width:480px`, `height:100%`. Every screen is `shell(inner)` (`function shell`) = `#root.innerHTML = inner + '<div id="modal">'`. Each screen is a `.screen` flex column (padding 14/16 px).

**Scaling.** `fitUI()` (~2217): on viewports ≥720×820 the whole `#root` is a 480 px column scaled by `k=min(vh/820, vw/480, 3)` (transform, `translateX(-50%)`); otherwise `k=1`, a plain column filling the phone. Popups `#ach-pop` are scaled with it. Canvases are sized separately from the stage box (`clientWidth/clientHeight`), so the scale does not change their logic size.

**Modals, dialogue, toasts.**
- `#modal` (CSS ~285): absolute over the whole `#root`, `z-index:10`, `pointer-events:none`; `openModal(html)` fills it, `closeModal()` empties it, `modalEl()` returns it. Its `.box` is centred (max 380 px). Used by pause menus, confirm boxes, login, popups.
- Toasts: `#toasts` (fixed, z 60, `pointer-events:none`), `TOAST` module (~2124): queue of one, `TOAST.hold()` keeps it compact while a maze or Ferma run is in play, `TOAST.place()` moves it onto the top bar if it would cover a control.
- Achievement popup `#ach-pop`: bottom, `popBottom()` = above the `.dpad`/`#fapad` (measured live).
- Dialogue: Blackjack `B.say` typewriter (`#btxt`); professor `PR.say` (`#ptxt`); battle narration in `.pbp`.

**Touch / pointer.**
- Maze: d-pad buttons (`data-d`), swipe on `#stage` (`touchmove` with `preventDefault`).
- Ferma: `#fapad` buttons via `pointerdown`/`pointerup`/`pointercancel` (`data-fk`, `FA_TOUCH`), the jump button `j`; the root `onclick` routes `data-fa` (popup buttons) and `#fap` (pause).
- Blackjack: the canvas and `.bmenu`/`.dpad` buttons (`bjClick` path); `touch-action:none` on `#bstage`.
- Professor: `prClick` on `root` (`data-pi`, battle `pbClick`).
- Global: `document` `pointerdown` (~1208) is the F5 long-press detector only; `pointerdown`/`touchstart`/`mousedown` clear the KNAV ring; `touchend` / `pointerdown` unlock audio (~1499).

**Android back: `mgback`** (~8286, the last listener, dispatched by the wrapper as a window event). Order: (1) open BUG/conflict/text-edit popup → its own `BUG.close`; (2) splash → `rocciaNo()`; (3) professor → `pbBack()` or leave a test run; (4) Blackjack → `bjPause()`; (5) Ferma → `faExit()`; (6) maze during an encounter (`G.state==="mini"`) → nothing; (7) any modal → `closeModal()` (except on the maze); (8) maze → `pauseMenu()` unless already paused; (9) any screen other than menu/bye → `applyFs()` and `go("menu")`; (10) menu → `tileAction("quit")` (the Quitta flow).

**Menu arrow navigation (U4, `KNAV`).** Pure focus ring, no game action: arrows move to the nearest item in that direction (`KNAV.move`, scored by along + 2×cross), Enter clicks. It is the only keyboard path on the menu and inside popups.

The shared freeze used by bug reports (`bugFreeze`, ~1382) returns a resume closure for all four games and is the cleanest existing hook for a "paused while the controller panel is open" rule.

## 4. Proposal (one paragraph, no code)

The least invasive way is a single layout switch on the shell, not a second renderer. Each game already sizes its canvas from its own container (`sizeCanvas` for the maze, `faSize` for Ferma, `bjSize` for Blackjack, `prSize` for the professor), and each container is a flex child of `#root` whose height is the screen height. A `handheld` flag (stored in the settings object, default off) would add a class to `#root` that (a) makes the play screens' `.hud` the top strip and the `#stage`/`#fastage`/`#bstage` box a fixed height of the screen minus a constant bottom zone (the controller's covered height, a setting), (b) pins the existing `.dpad`/`#fapad` (or a new bottom zone) into that zone, and (c) inserts a one-line bar (`#hbar`) just above it that shows «Start: Pausa», a status text and «Select: Co-op». Because every game already reads its container size on `resize`, nothing in the simulation changes; the professor's `.prs` is full screen and would need only its `.pbp` panel moved into the bottom zone. The mode is decided once at boot and on Opzioni › Controller, and the pause overlays keep using `#modal`, which already sits over the whole `#root`, so they open over the top area without new markup. The gamepad mapping would go through one input module that turns button indices into the existing actions (`setDir`, `faJump`, `bjConfirm`, `pauseMenu`, the global Enter/Escape), so no game file reads raw buttons.
