# Contributing
1. Open the live build and enable developer mode (tap "Build locale" 5 times in Options).
2. Make your changes locally (text, audio, sprites).
3. Put them in `submissions/<your-name>/<YYYY-MM-DD>/` with a `manifest.json` (copy `submissions/_template/manifest.json`).
4. Open a pull request. Do not edit `index.html` or `builds/`.
5. The maintainer has Claude verify and list your changes. If approved, they are hardcoded into the next build (e.g. `V0.2_6`) and go live automatically.

Rules: assets never cross characters (Uomo roccia: planes/rocks; Algidone: gym equipment/snacks), all text in Italian, keep files small (the game is one HTML file with embedded assets).
